# EXE 빌드와 배포

Windows Python 3.10 이상(64비트, tkinter 포함)을 사용합니다. 저장소 루트에서 다음을 실행하세요.

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --clean --distpath dist --workpath .build\pyinstaller packaging\JOB_Signal_Explorer.spec
```

결과는 `dist\JOB_Signal_Explorer.exe`입니다. spec 파일은 `src/`의 두 Python 파일과 `packaging/`의 Tcl/Tk 훅을 참조합니다. 일반 Windows Python에서는 PyInstaller 기본 tkinter 훅만으로 빌드할 수도 있지만, 이 프로젝트의 spec은 기존 배포 환경에서 사용한 리소스 수집 방식을 유지합니다.

테스트용 가상 JOB 파일로 추출, GUI 초기화, Excel 저장을 검사합니다.

```powershell
.venv\Scripts\python -m unittest discover -s tests -p "test_*.py" -v
.\dist\JOB_Signal_Explorer.exe --self-test ".\tests\fixtures\sample.job" ".\dist\self_test.json"
```

자체 검사는 지정한 JSON 옆에 XLSX도 만듭니다. 배포 ZIP과 소스 ZIP을 만들려면 다음을 실행합니다.

```powershell
.venv\Scripts\python packaging\package_release.py
```

ZIP과 EXE는 `dist/`에 생성되며 Git에서 제외됩니다. 이전 `outputs/`와 `work/`의 파일은 빌드 과정에서 사용하거나 변경하지 않습니다.
