# JOB Signal Explorer

## 팀원에게 전달할 파일

`JOB_Signal_Explorer.exe` 하나만 전달하면 됩니다. Windows 10/11 64비트용이며 Python이나 Excel 설치 없이 실행·엑셀 저장이 가능합니다. 인터넷 연결도 필요 없습니다.

1. EXE를 더블클릭합니다.
2. **JOB 파일 추가**에서 Ctrl/Shift로 여러 파일을 선택합니다. **폴더 추가**는 하위 폴더까지 읽습니다.
3. 왼쪽 **신호 목록** 또는 **프로그램 목록**에서 항목을 선택합니다.
4. **주석 / 사용 내역**에서 원하는 행을 클릭하면 아래 원본 텍스트의 해당 줄이 강조됩니다.
5. **연결 그래프** 탭에서 신호 ↔ 프로그램 연결을 확인합니다. 노드를 클릭하면 그 항목을 중심으로 이동합니다.
6. **엑셀 저장…**을 눌러 원하는 경로에 저장합니다.

## 화면과 데이터

- 검색창은 신호명, 주석, 파일 경로를 검색합니다. DI/DO 필터는 신호 목록에 적용됩니다.
- 그래프는 선택한 항목과 직접 연결된 항목을 보여줍니다. 화면 혼잡을 줄이기 위해 한 페이지 16개씩 표시하며 이전/다음 버튼으로 모두 확인할 수 있습니다.
- 파일은 추가 방식으로 읽습니다. 같은 전체 경로를 다시 추가하면 내용을 갱신합니다. 다른 폴더의 같은 파일명은 각각 유지하며 선택 시 전체 경로가 표시됩니다.
- **목록 초기화**는 현재 불러온 목록만 비웁니다. 원본 JOB은 수정하지 않습니다.
- 화면 원본은 불러온 시점의 내용입니다. 외부에서 JOB을 수정했다면 다시 추가해 갱신하세요.
- 종료하면 목록이 초기화됩니다. 다음 실행 때 필요한 파일을 다시 선택하세요.
- 로봇마다 같은 신호 번호의 용도가 다르면 로봇별로 따로 불러오세요.
- 인코딩은 자동이 기본입니다. 한글이 깨지는 파일은 인코딩을 CP949 등으로 바꾼 뒤 같은 파일을 다시 추가하세요.

## 엑셀

화면의 검색·필터 상태와 관계없이 **불러온 전체 파일**을 저장합니다.

- **신호 요약**: 신호별 주석 목록, 횟수, 사용 파일 전체 경로 목록.
- **사용 내역**: 모든 사용 위치. 파란 주석 또는 줄 번호를 클릭하면 원본 텍스트 시트로 이동합니다.
- **처리 파일**: 파일명, 전체 경로, 인코딩, 추출 건수.
- **원본 텍스트**: 불러온 파일의 모든 줄. 원본 파일이 없는 팀원도 엑셀 내부 링크로 근거를 볼 수 있습니다.

주석과 원본은 기록 그대로 보존합니다. 주석 없는 신호도 포함합니다. 추출 문법은 기존 `사용방법.md`를 참고하세요. 동적 주소와 별칭, CALL 대상의 자동 추적은 지원하지 않습니다.

## Python으로 수정해서 실행

Python 3.10 이상에서 `py -m pip install -r requirements.txt` 후 저장소 루트에서 `py src\job_signal_viewer.py`를 실행합니다. EXE 재빌드는 `빌드방법.md`를 참고하세요.
