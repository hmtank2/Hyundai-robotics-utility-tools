# 현대 로봇 JOB 신호 추출기

Python 3.10 이상에서 동작합니다. 원본 JOB 파일은 읽기만 합니다.

## 처음 한 번 설치

이 프로그램을 저장한 폴더에서 터미널을 열고 실행하세요.

```powershell
py -m pip install -r requirements.txt
```

## 파일 선택 창으로 실행

```powershell
py src\job_signal_extractor.py
```

JOB 파일을 여러 개 선택하고 엑셀 저장 위치를 선택합니다. Windows용 일반 Python 설치의 tkinter를 사용합니다.

## 명령줄 실행

```powershell
py src\job_signal_extractor.py "C:\작업\0001.job" -o "결과.xlsx"
py src\job_signal_extractor.py "C:\작업\0001.job" "C:\작업\0002.job" -o "결과.xlsx"
py src\job_signal_extractor.py "C:\작업\JOB폴더" -r -o "전체신호.xlsx"
```

폴더 지정 시 `.job` 파일만 읽습니다. `-r`을 붙이면 하위 폴더까지 검색합니다.
동일 파일을 중복 지정해도 한 번만 읽습니다. 서로 다른 폴더의 동명 파일은 각각 처리합니다.
기존 출력 파일 덮어쓰기는 `--overwrite`를 붙이세요. 열려 있는 출력 엑셀은 먼저 닫으세요.
인코딩은 UTF-8 → CP949 순서로 확인하고, BOM이 있는 UTF-16도 지원합니다.
자동 판별이 맞지 않으면 `--encoding cp949` 등으로 직접 지정할 수 있습니다.
읽기 실패 시 파일을 조용히 누락하지 않고 전체 작업을 실패 처리합니다.

## 엑셀 구성

- **신호 요약**: DI/DO 및 번호 순으로 정렬. 신호별 서로 다른 주석을 줄바꿈으로 모으고 출현 횟수, 파일 수, 주석 종류 수, 주석 없는 횟수를 표시합니다.
- **사용 내역**: 모든 출현을 보존. 신호, 명시된 비교/대입 연산자와 0/1 값, 주석, 파일명, 실제 줄 번호, 명령문, 전체 경로, 원본 줄을 표시합니다.
- **처리 파일**: 신호가 하나도 없는 파일도 포함한 입력 파일 목록, 인코딩, 추출 건수입니다.

요약의 주석 종류 수가 여러 개인 것은 ON/OFF 표현 차이일 수도 있고 실제 용도 차이일 수도 있습니다. 프로그램은 해석하거나 수정하지 않습니다.

## 추출 규칙과 범위

`di40`, `wait di40`, `if di73==1`, `do40=0`, `do40 = 1`, `wait do31` 등 명령 위치와 무관하게 DI/DO 숫자 토큰을 찾습니다. 대소문자를 구분하지 않습니다. `wait`의 생략된 값을 1로 추정하지 않습니다.

따옴표 밖 첫 `#` 이후 텍스트를 같은 줄 모든 신호의 주석으로 저장합니다. 앞뒤 공백과 첫 `#`만 제거하며, 후속 `#`은 보존합니다. 한 줄에 여러 신호가 있으면 같은 주석을 공유합니다.
주석만 있는 줄과 따옴표 안 문자열의 DI/DO는 제외합니다. 주석이 없는 신호도 보존하며 앞뒤 줄의 주석을 가져오지 않습니다.

정적 텍스트 검색이므로 실행되지 않는 분기에도 있는 신호를 포함합니다. 신호 번호만 같으면 선택한 모든 파일에서 통합하므로, 로봇별 신호 체계가 다르면 각각 실행하세요.
`call` 대상 파일을 자동으로 찾아 읽지는 않습니다. 관련 JOB들을 함께 선택하거나 폴더를 지정하세요.
동적 주소(`di[변수]` 등), 별칭, 다른 종류 신호는 지원 범위 밖입니다. 현대 JOB 언어 전체 문법 해석기가 아니며 샘플과 위 표기법을 기준으로 합니다.

명시 값은 신호 바로 뒤에 비교/대입 연산자와 단독 0/1이 있는 경우만 기록합니다. 복잡한 식은 원본 명령문에서 확인하세요.
엑셀 값은 추출 시점의 고정 결과입니다. JOB이 변경되면 다시 실행하세요.
